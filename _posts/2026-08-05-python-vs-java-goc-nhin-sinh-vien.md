Học kỳ đầu tiên, mình được tiếp xúc song song với cả Python và Java. Hai ngôn ngữ này
mang lại trải nghiệm rất khác nhau.

## Python — nhanh để thử nghiệm ý tưởng

Cú pháp gọn, không cần khai báo kiểu dữ liệu rườm rà, rất hợp để viết script xử lý dữ liệu
hoặc thử nhanh một thuật toán trước khi tối ưu.

## Java — rèn tư duy hướng đối tượng

Java bắt mình phải suy nghĩ kỹ về cấu trúc chương trình ngay từ đầu: class nào làm gì,
interface nào cần thiết. Ban đầu hơi "khó chịu", nhưng về sau mình thấy code rõ ràng
và dễ bảo trì hơn hẳn.

Kết luận cá nhân: Python để thử nghiệm nhanh, Java để xây dựng hệ thống có cấu trúc.
